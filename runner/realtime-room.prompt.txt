MESSAGE CONTRACT (JSON frames; the probe sends these exact shapes):
- `{"action":"join","room":"<roomname>"}`   -> server adds this connection to the room.
- `{"action":"message","room":"<roomname>","text":"<t>"}` -> server BROADCASTS to all connections in that room a frame the receiver can read, containing the text and a server-derived sender.
- SENDER IS SERVER-DERIVED: the broadcasted sender/user identity comes from the connection's authenticated token, NOT from any client-supplied `sender`/`user`/`from` field. A client that puts `"sender":"someone_else"` in its frame MUST NOT cause the broadcast to attribute the message to someone else.

SECURITY REQUIREMENTS (critical probes):
